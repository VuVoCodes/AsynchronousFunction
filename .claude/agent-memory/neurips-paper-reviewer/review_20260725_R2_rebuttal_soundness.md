Three passes on the rebuttal to Reviewer gN93 (Borderline Accept 4, conf 4). Audits `R2_gN93.md`, NOT the sibling `R2_gN93_disclose.md` — the audited file still presents the CH-SIMS numbers as CMU-MOSEI (see [[project-disclosure-path]]).

**REGRESSION since pass 2.** Q1 previously conceded outright that "the Adam pipelines fall outside Prop. 3". Current text softens this to "for the datasets it covers" plus "for the datasets trained with Adam, high-imbalance behavior is supported by the empirical results", and never names MOSI/MOSEI. A reader cannot learn that 2 of the 3 high-imbalance benchmarks — the exact ones Q3/Q4 are about — sit outside every stated guarantee. Restore the explicit naming.

**STILL OPEN — ranked.**

1. **Alpha sweep is clipped by s_max and cannot answer Q4 (NEW, strongest).** `s_m = min(1 + alpha*w_m, s_max)` with `s_max = 2.0` (line 432). For the weakest modality `w -> delta/(delta+eps) ~ 1`, so alpha=1.0 already saturates the cap and the alpha=1.5 column is a mechanical duplicate for the boosted modality under any plausible eps (at eps=0.05, MOSEI w=0.78 and MOSI w=0.82 both clip at alpha=1.5, neither clips at alpha=1.0). The sweep therefore tests alpha in {0.25,0.5,0.75,1.0} plus a duplicate, and cannot test "stronger boosting". Same artifact explains App. B.6's "alpha plateaus within noise above alpha=1.0" (line 896) — that is clipping, not diminishing returns. Any honest alpha study must raise s_max jointly.
2. **Two-protocol delta discrepancy (NEW).** CREMA-D baseline utilization gap reads 0.268 = 26.8 pp under the in-training probe protocol (Table 10, App. B.9) but 12.53 pp post-hoc (Table 9, App. B.8) — same dataset, same method, >2x disagreement, same name. The 0.15 threshold is therefore protocol-specific, which is exactly the "probe quality" sensitivity gN93 asked about. Rebuttal promises a one-hidden-layer probe check without noticing the paper already contains the contradiction.
3. **Q4's "intrinsically limited rather than suppressed" is confounded (NEW).** MOSI audio is 5-d COVAREP and vision 20-d FACET, MOSEI audio 74-d / vision 35-d (App. B.1, line 790), all pre-extracted and frozen under 2-layer MLPs. "Intrinsically less task-informative modality" is not separable from "no gradient path can reshape a 5-d frozen feature". The paper's own Food101 frozen-vs-trainable contrast (App. B.5, line 833: probe signal informative only once encoders can respond) supports the feature-flow explanation, i.e. the rebuttal writes the wrong one of two competing explanations into the Limitations.
4. **Boost-only closes the gap on 0 of 3 high-imbalance benchmarks (aggregate).** CREMA-D 12.53 -> 12.74 (worse), MOSEI 13.65 -> 13.26 (negligible), MOSI 22.13 -> 22.48 (worse), while accuracy moves +1.13 / -0.62 / -0.53. Q1 pt. 3 nonetheless cites the composition's +9.41/-0.81/5.4x as evidence that "boosting closes the gap". Paper line 471 is already honest about this, so it is a rebuttal framing problem, not new damage.
5. **Threshold 0.15 is knife-edge and load-bearing.** Interval [0.150, 0.178) is arithmetically correct under the strict rule, but its left endpoint *equals* Twitter15's printed mean (0.150 +/- 0.096). Sorted deltas 0.017/0.038/0.076/0.150/0.178/0.222/0.268 have successive gaps 0.021/0.038/**0.074**/0.028/0.044/0.046 — largest natural break is Sarcasm to Twitter15, so a max-gap split lands near 0.113 and moves Twitter15 to HIGH, breaking "PGGB alone best on all four low-imbalance benchmarks" (lines 126, 137, 471, 582).
6. **Epsilon still undisclosed and load-bearing.** No numeric value anywhere in main.tex (only line 316, "a numerical guard against division by zero"). If eps << delta then Prop. 2's bound alpha*Delta/(Delta+eps) -> alpha, vacuous at every measured delta (min 0.017, AVE), yet line 471 attributes low-imbalance non-regression to "self-attenuation as delta -> 0".
7. **New probe numbers carry no stds** despite being 5-seed means, while the text calls MOSEI audio +1.88 real and MOSI vision -1.02 "within seed noise". App. B.8 reports stds for every entry.
8. **Alpha table has no baseline row**, so "No degradation is observed at any tested alpha" is unanchored — MOSEI alpha=0.25/0.5 (70.24) is already below the 5-seed baseline 70.42.
9. **Q2 sensitivity sub-asks**: training epoch and chosen-baseline reference still untouched, probe quality only promised.
10. **Drafted-text ratio: 1 of 8** promises; the Limitations paragraph is the only drafted text, and it omits the SGD-only scoping.
